# ผู้ให้บริการข้อมูลฟุตบอลของ Match Center

บันทึกผลทดสอบจริง วันที่ **11 สิงหาคม 2026** — ทดสอบด้วยคีย์แพ็กฟรีของทั้งสองเจ้า
ยิงผ่าน endpoint ของ GOG เองบนเครื่อง ไม่ใช่การอ่านจากเอกสารของผู้ให้บริการ

---

## 1. สรุปสิ่งที่แพ็กฟรีให้จริง

| ความสามารถ | football-data.org | API-Football |
|---|---|---|
| ปฏิทินโปรแกรมแข่ง 2026/27 | ใช้ได้ — 380 นัดครบ | **ใช้ไม่ได้** |
| ตารางคะแนน | ใช้ได้ — 20 ทีม | **ใช้ไม่ได้** |
| เหตุการณ์ในเกม | ไม่มีในแพ็กฟรี | ใช้ไม่ได้ (ติดข้อจำกัดฤดูกาล) |
| ไลน์อัพ | ไม่มีในแพ็กฟรี | ใช้ไม่ได้ (ติดข้อจำกัดฤดูกาล) |
| สถิติแมตช์ | ไม่มีในแพ็กฟรี | ใช้ไม่ได้ (ติดข้อจำกัดฤดูกาล) |
| Head-to-head | ไม่มีในแพ็กฟรี | **ถูกบล็อกแยกต่างหาก** |

ข้อความที่ API-Football ตอบกลับมาตรง ๆ:

```
Free plans do not have access to this season, try from 2022 to 2024.
Free plans do not have access to the Last parameter.
```

แปลว่า **แพ็กฟรีของ API-Football เข้าถึงได้แค่ฤดูกาล 2022–2024** ใช้กับ 2026/27 ไม่ได้เลย
ส่วน head-to-head ถูกปิดต่างหากอีกชั้นหนึ่ง ไม่เกี่ยวกับเรื่องฤดูกาล

## 2. สิ่งที่เลือกทำตอนนี้

**อยู่กับ football-data.org ไปก่อน ไม่จ่ายเงินเพิ่ม**

ผลที่ได้จริงบนหน้าเว็บ:

- ปฏิทินโปรแกรมแข่ง · ผลการแข่งขัน · ตารางคะแนน — **ข้อมูลจริงทั้งหมด**
- แท็บเหตุการณ์ / ไลน์อัพ / สถิติ / H2H — ขึ้นสถานะ "ยังไม่มีข้อมูล" พร้อมเหตุผล
  ซึ่งเป็นพฤติกรรมที่ถูกต้อง ไม่ใช่บั๊ก
- ป้าย DEMO DATA หายไปแล้ว เพราะไม่ได้ใช้ข้อมูลสมมติอีก

คีย์ของ API-Football ยังใส่ไว้ในระบบ ไม่ต้องถอดออก — พอมีสิทธิ์เข้าถึงฤดูกาลปัจจุบัน
เมื่อไหร่ ระบบจะเริ่มใช้เองอัตโนมัติโดยไม่ต้องแก้โค้ด

**ผลข้างเคียงที่ยอมรับไว้:** ทุกครั้งที่แคชปฏิทินหมดอายุ ระบบจะยิงถาม API-Football
แล้วได้ error กลับมา เสียโควตาไปเปล่า ๆ ประมาณวันละไม่กี่ครั้ง
(แคชปฏิทิน 6 ชั่วโมง แคชตารางคะแนน 6 ชั่วโมง) ยังห่างจากเพดาน 100 ครั้ง/วันมาก
จึงยังไม่คุ้มที่จะเขียนตรรกะกันไว้เป็นพิเศษ ถ้าอนาคตเพิ่มรายการแข่งอื่นค่อยมาทบทวน

## 3. ทางเลือกเมื่ออยากได้ครบทุกแท็บ

### ทางที่ 1 — ทดสอบท่อด้วยฤดูกาลเก่าก่อน (ไม่เสียเงิน)

แก้ค่าเดียวใน `services/football/competitions.ts`

```ts
export const DEFAULT_SEASON = "2023";
```

จะได้เห็นว่า adapter ที่เขียนไว้อ่านเหตุการณ์ ไลน์อัพ และสถิติได้ถูกจริงไหม
ก่อนตัดสินใจจ่ายเงิน — คุ้มค่าที่จะทำก่อนอัปเกรด

ข้อควรระวัง: ปฏิทินจะกลายเป็นของฤดูกาล 2023/24 ทั้งหมด
และต้องล้างแคชก่อน ไม่งั้นยังเห็นของเดิม (ดูข้อ 5)

### ทางที่ 2 — อัปเกรด API-Football

ราคาเริ่มต้นประมาณ €19/เดือน ได้ฤดูกาลปัจจุบันและ endpoint ที่ถูกบล็อกทั้งหมด
ใส่คีย์เดิมได้เลย ไม่ต้องแก้โค้ด

### ทางที่ 3 — TheSportsDB

ยังไม่ได้เขียน adapter ตัวนี้ คีย์ฟรีสาธารณะคือ `123` ไม่ต้องสมัคร
มีข้อจำกัดที่ต้องรู้ก่อนลงแรง: จำกัด 30 ครั้ง/นาที · การค้นหาทีมในแพ็กฟรี
จำกัดไว้ที่ Arsenal เท่านั้น · ตารางแข่งของทีมในแพ็กฟรีเห็นเฉพาะเกมเหย้า
เหมาะกับงานเสริมอย่างโลโก้สโมสรและข้อมูลสนามมากกว่าเป็นแหล่งข้อมูลหลัก

**เรื่องสิทธิ์ภาพ:** URL รูปจาก API ไม่ได้แปลว่าได้สิทธิ์ใช้เชิงพาณิชย์
โลโก้สโมสรและรูปนักเตะเป็นทรัพย์สินทางปัญญาแยกจากข้อมูลสถิติ ต้องตรวจสิทธิ์ก่อนใช้จริง

## 4. บทเรียนจากการต่อของจริง

ข้อมูลสมมติผ่านหมดทุกอย่าง แต่พอต่อของจริงเจอบั๊กสามอันทันที
บันทึกไว้กันพลาดซ้ำตอนเพิ่มผู้ให้บริการรายใหม่

1. **ชื่อทีมไม่เหมือนกันระหว่างเจ้า** — football-data.org เติม `FC` / `AFC` ท้ายชื่อ
   ทำให้แปลไทยไม่ได้ 19 จาก 20 ทีม และที่หนักกว่าคือ `gogTeamId` สร้างจากชื่อทางการ
   ทีมเดียวกันจากคนละเจ้าจึงได้ id คนละตัว ระบบจับคู่เอนทิตีพังทั้งระบบ
   แก้ที่ `normalizeName` ให้ตัดคำบอกประเภทสโมสรที่หัวและท้าย

2. **ห้ามเอา id ของเจ้าหนึ่งไปยิงถามอีกเจ้าเด็ดขาด** — ครั้งแรกระบบส่ง id ของ
   football-data.org ไปถาม API-Football ซึ่งตีความเป็นแมตช์อื่น แล้วคืนเหตุการณ์
   กับไลน์อัพของแมตช์ที่ไม่เกี่ยวข้องกันเลยโดยไม่มีอะไรเตือน
   **แย่กว่าไม่มีข้อมูล เพราะดูเหมือนถูกต้องทุกประการ**
   ตอนนี้ยิงถามได้เฉพาะเจ้าที่มี id ของแมตช์นั้นจริงเท่านั้น

3. **รหัสรายการแข่งใช้ร่วมกันไม่ได้** — API-Football ใช้ `39`
   ส่วน football-data.org ใช้ `PL` แยกเป็นตารางแมปใน `competitions.ts`

## 5. คำสั่งที่ใช้บ่อย

ล้างแคชข้อมูลฟุตบอลบนเครื่อง (จำเป็นทุกครั้งที่แก้ตรรกะการแปลงข้อมูลหรือเปลี่ยนฤดูกาล):

```powershell
$db = Get-ChildItem -Recurse -Filter "*.sqlite" .wrangler\state\v3\d1 | Select-Object -First 1
npx wrangler d1 execute gog-newsroom-db --local --command "DELETE FROM football_cache"
```

ดูว่าผู้ให้บริการเจ้าไหนล้มเพราะอะไร:

```powershell
npx wrangler d1 execute gog-newsroom-db --local --command "SELECT provider, endpoint, ok, error, created_at FROM football_provider_log ORDER BY id DESC LIMIT 20"
```

ตรวจความครอบคลุมข้อมูลของแต่ละแมตช์บนหน้าเว็บ — เปิด `?datalab=1` แล้วเข้าหน้าแมตช์

## 6. ใส่คีย์ที่ไหน

- **บนเครื่อง** — ไฟล์ `.dev.vars` (ถูก gitignore แล้ว ห้าม commit เด็ดขาด repo นี้เป็น public)
- **บน production** — เป็น secret ของ Cloudflare

```powershell
npx wrangler secret put FOOTBALL_DATA_KEY --config dist/server/wrangler.json
npx wrangler secret put API_FOOTBALL_KEY  --config dist/server/wrangler.json
```

ไม่ใส่คีย์เลยก็รันได้ ระบบจะกลับไปใช้ข้อมูลตัวอย่างและติดป้าย DEMO DATA ให้เอง

**เรื่องเงื่อนไขการใช้งาน:** "ฟรี" ไม่ได้แปลว่าใช้เชิงพาณิชย์ได้
ทั้งสองเจ้ามีเงื่อนไขเรื่องการใช้เชิงพาณิชย์ การเก็บแคช และการแสดงเครดิต
ต้องอ่านให้จบก่อนเปิดให้คนนอกใช้ โดยเฉพาะถ้าจะมีรายได้จากบริการทริป
